# Cluck N' Cook

<img width="1134" height="209" alt="IMG_8403" src="https://github.com/user-attachments/assets/e0fb8f06-117f-4732-a3d2-55d1aa98139b" />

Cluck N' Cook is a wave-based cartoony action shooter game developed for the Shiba Arcade game jam in the later months of 2025. The in person hackathon itself occured in November of 2025. This is a personal github publication for myself that I used to track my progress. For anybody interested in compiling the game and accessing a playable/modifiable version, you may do so by first downloading the "new-project" folder and importing it into Godot where it will be recognized as a valid project and can be opened.
